Free electrician exam prep
Flashcards and practice questions on the 2023 NEC, grounding and bonding, Wisconsin code changes and electrical safety. Free, no account needed.
Study practice written by VoltCE. These are not official exam questions and do not earn continuing-education credit. Always check the code book and your state licensing board for what applies to you.
Load calc & sizing practice
Thousands of free practice problems: conductor sizing, branch circuits, dwelling and commercial loads, motors, transformers with secondary protection, parallel conductors, conduit fill (several conduit types and insulations), voltage drop, grounding and box fill. Every answer comes with the worked solution.
Based on the 2023 NEC. Unless a problem says otherwise, assume 75°C-rated terminations, copper conductors and standard overcurrent device sizes from 240.6(A). Study practice written by VoltCE, not official exam questions, and no CE credit. Have your code book handy.
Master electrician exam prep
Free, and built for the harder exam: multi-step design calculations, services and feeders, motors, transformers, short-circuit current, hazardous locations and Wisconsin practice. Every answer shows the worked solution and the code reference.
Based on the 2023 NEC, with 75°C terminations, copper conductors and standard sizes from 240.6(A) unless a problem says otherwise. Study practice written by VoltCE, not official exam questions, and no CE credit. Have your code book and calculator ready. See a wrong answer? Use Report this question; corrections help most.

Practice by code cycle
States adopt different editions of the NEC. Pick your exam level and the code cycle you are being tested on, then study only questions that are correct for that edition. A separate mode drills what changed when each cycle arrived.
Each question is tagged with the editions where its answer holds true, so a rule that changed is never marked wrong for the older cycle. Always confirm which edition your state and exam use. Study practice written by VoltCE, not official exam questions, and no CE credit.

Code book index lookup drill
